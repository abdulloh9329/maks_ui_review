# Max — UI review (compared with Bolt)
*[O'zbekcha → README.md](README.md)*

**Max** is a ride-hailing, food delivery and courier app for Uzbekistan. We want its screens to reach Bolt-level usability, and we'd love your feedback — designers, developers and riders from anywhere are welcome.

> Bolt images are reference only for discussion; Max keeps its own brand. Personal data is blurred.
> This repository contains no code — only images and text.

## How to give feedback
1. Open a screen page and compare Bolt with Max.
2. Comment in the matching discussion under **Issues** (each is labelled `muhokama` = discussion).
3. Have a new idea? *New issue → Fikr (Feedback)* template.

Feedback in English, Uzbek or Russian is welcome. See [CONTRIBUTING.md](CONTRIBUTING.md).
