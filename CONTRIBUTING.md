# Qanday hissa qo'shish mumkin

- Hurmat bilan yozing, aniq misol keltiring (qaysi ekran, nima noqulay, qanday bo'lishi kerak).
- Rasm yoki eskiz qo'shsangiz, unda shaxsiy ma'lumotlar (telefon, manzil, ism) bo'lmasin.
- Bu repo'ga kod yubormang — faqat dizayn fikrlari.
- Bolt yoki boshqa brendlarning logotiplarini Max uchun taklif qilmang; Max o'z brendini saqlaydi.

---

## English

- Be respectful and specific (which screen, what is inconvenient, how it should be).
- If you attach an image or sketch, make sure it has no personal data (phone, address, name).
- Please don't submit code to this repo — design feedback only.
- Don't propose Bolt's or other brands' logos for Max; Max keeps its own brand.
